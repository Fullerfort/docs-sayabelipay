---
title: Payment Methods Available
description: "GET /api/fpx_bank_list"
---

Returns the payment methods currently available on your account. Despite the endpoint's name, it lists **payment methods**, not individual banks — the customer picks their bank on the checkout page.

## Request

```bash
curl https://sayabelipay.com/api/fpx_bank_list \
  -u "YOUR_CLIENT_ID:YOUR_CLIENT_SECRET"
```

No parameters.

## Response

```json
{
  "status": 200,
  "data": {
    "available_payment_methods": ["fpx", "fpx_b2b1", "dnqr", "duitnow_qr"],
    "names": {
      "fpx": "FPX B2C",
      "fpx_b2b1": "FPX B2B1",
      "dnqr": "Duitnow QR",
      "duitnow_qr": "Duitnow Qr"
    }
  }
}
```

`available_payment_methods` uses the payment processor's own codes, which differ from the `channel` values you send when [creating a payment](/api-reference/create-payment):

| Code in this list | `channel` to send |
|---|---|
| `fpx` | `FPX` |
| `dnqr` / `duitnow_qr` | `DUITNOW_QR` |

Other codes may appear (for example `fpx_b2b1`, corporate FPX); only the channels in [Payment Channels](/guides/payment-channels) can be used to create a payment. In sandbox the list is longer, because the test environment enables extra methods.
